# Yerigan Labs Vision

Yerigan Labs exists to design, build, document, secure, and operate enterprise-quality infrastructure that serves three connected purposes.

## Home and Family

Create reliable and secure services that improve our family's digital life, including:

- Centralized storage and backups
- Family photo and video management
- Media streaming
- Smart-home integration
- Network security and filtering
- Secure remote access
- Resilient recovery procedures

## Career Development

Build practical experience in:

- Linux administration
- Windows Server and Active Directory
- Networking and segmentation
- Virtualization
- Docker and containers
- Monitoring and observability
- Cybersecurity operations
- Automation and infrastructure as code
- Documentation and change management

## Future Business

Develop reusable knowledge, procedures, demonstrations, and technical capabilities that could support a future cybersecurity consultancy, MSP, or MSSP.

## Engineering Principles

1. Understand why a system exists before deploying it.
2. Prefer secure defaults and least privilege.
3. Verify effective configuration rather than assuming changes worked.
4. Document decisions, implementation, testing, and recovery.
5. Design services to be maintainable and recoverable.
6. Balance career value with practical value for the household.
7. Use the right tool for the problem rather than merely a tool that works.
