Device Naming Standard

This is something I actually feel pretty strongly about.

Every device should answer:

Where is it?

What is it?

Examples:

Kitchen Ceiling Light

Kitchen Island Pendant

Living Room TV

Living Room Lamp

Office Desk Lamp

Front Door Lock

Garage Motion Sensor

Primary Bedroom Curtains

Front Porch Camera

Notice we don't include the manufacturer.

Bad:

Kasa Plug

Aqara Motion

SwitchBot Curtain

Good:

Coffee Maker Outlet

Garage Motion Sensor

Living Room Curtains

Manufacturers change.

Functions usually don't.

Entity Naming

Later, under the hood, we'll standardize entity IDs.

For example:

light.kitchen_ceiling

lock.front_door

camera.driveway

binary_sensor.garage_motion

Nice.

Predictable.

Easy to automate.

Backup Philosophy

One of the best things Home Assistant added recently is built-in backups.

I'd like backups to eventually go to:

Local storage
NAS (future)
Cloud (optional)

The key principle is: if the mini-PC dies, you should be able to restore your Home Assistant configuration and automations without starting from scratch.
