Purpose

Create and validate a Home Assistant mobile notification.

Prerequisites

- Home Assistant installed
- Companion App connected
- Mobile device registered

Procedure

1. Open Home Assistant.
2. Navigate to Automations.
3. Create Automation.
4. Select Device Trigger.
5. Select target device.
6. Choose desired state.
7. Add Notify Mobile App action.
8. Test.
9. Validate notification delivery.

Expected Result

Notification appears on mobile device.

Troubleshooting

If notification fails:

- Verify mobile app registration.
- Verify correct notify.mobile_app action.
- Check automation trace.
- Validate configuration.
