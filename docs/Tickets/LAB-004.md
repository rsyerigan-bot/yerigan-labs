Why Caddy?

I'm intentionally choosing Caddy over Nginx Proxy Manager for a few reasons.

Nginx Proxy Manager is a fantastic tool.

But...

Caddy is:

configuration-as-code
Git friendly
simple
automatic HTTPS (later)
easier to version control
easier to deploy to future clients

Remember one of your goals?

Everything should become part of your future company.

That means I'd rather have you learn something that scales well into automation and Infrastructure as Code.
