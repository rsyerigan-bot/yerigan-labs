# Yerigan Labs

Yerigan Labs is a documented homelab and engineering environment built to support:

- Home and family services
- Career development in infrastructure and cybersecurity
- A possible future MSP, MSSP, or consulting business

## Current Environment

- Proxmox VE host
- Ubuntu Server VM
- Docker
- Portainer
- Pi-hole
- Homepage
- Uptime Kuma
- SSH public-key authentication
- Static server addressing
- QEMU Guest Agent

## Repository Structure

- `docs/engineering-journal/` — Detailed implementation lessons and outcomes
- `docs/engineering-decisions/` — Decisions, alternatives, and trade-offs
- `docs/runbooks/` — Repeatable operating and recovery procedures
- `docs/architecture/` — Network and system architecture
- `docs/interview-notes/` — Career-focused explanations and questions
- `infrastructure/docker/` — Docker Compose and application configuration
- `scripts/` — Administration and automation scripts
- `diagrams/` — Visual architecture diagrams
