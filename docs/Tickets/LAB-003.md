# LAB-003 — Secure the Ubuntu Platform

**Status:** In Progress

## Objective

Establish a documented Ubuntu security baseline while preserving required management and household services.

## Completed Milestones

- Inventoried listening ports, enabled services, and Docker containers
- Studied Linux and Docker packet flow
- Documented current and target network architecture
- Defined future network security zones
- Migrated Portainer from a standalone container to Docker Compose
- Removed the unused Portainer Edge Agent host publication on TCP 8000
- Restricted Portainer publication to `192.168.1.203:9443`
- Enabled unattended security updates
- Configured UFW with default-deny inbound and default-allow outbound policies
- Restricted SSH and approved service ports to `192.168.1.0/24`
- Enabled UFW at startup
- Confirmed VS Code Remote SSH remained operational

## Pending Milestones

- Verify a new PowerShell connection using `ssh ubuntu-lab`
- Verify all approved services remain reachable
- Confirm Uptime Kuma remains healthy
- Implement Docker filtering through `DOCKER-USER`
- Document firewall verification and rollback procedures
- Complete final security review

## Current Limitation

Docker-published ports may bypass ordinary UFW input rules because Docker manages forwarding and NAT rules separately. UFW is active, but the Docker-specific firewall policy is not yet complete.
