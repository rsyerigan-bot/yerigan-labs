# LAB-009 — Presence and Occupancy

## Objective

Build a multi-signal presence and occupancy model for Home Assistant.

## Success Criteria

- Mobile device presence identified
- Person entity associated with mobile tracker
- Home/Away state validated
- Wi-Fi/network presence evaluated as a secondary signal
- Presence failure scenarios documented
- Architecture prepared for motion and AI-based occupancy signals

### Evidence Sources

- GPS / Home Assistant Person entity
- iPhone-reported Wi-Fi SSID

### Presence States

| GPS | Wi-Fi | Result |
|---|---|---|
| Home | Home Wi-Fi | Confirmed Home |
| Home | Not Home Wi-Fi | Likely Home |
| Away | Home Wi-Fi | Conflicting Evidence |
| Away | Not Home Wi-Fi | Away |

### Validation Finding

Phone-reported SSID cannot currently serve as a reliable negative network-presence signal because Home Assistant is only locally accessible.

When Wi-Fi is disabled, the phone loses its path to Home Assistant and may leave a stale SSID value.

### Recommendation

After migration to the permanent network, implement network-side presence detection using the router/access point.
