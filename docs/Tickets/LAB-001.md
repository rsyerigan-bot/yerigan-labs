# LAB-001 — Secure Remote Administration

**Status:** Complete

## Objective
Replace password-based SSH logins with passphrase-protected Ed25519 key authentication.

## Deliverables
- SSH key pair generated
- Windows SSH profile created
- Public key installed
- Password authentication disabled
- Root login disabled
- SSH documentation completed
- Baseline architecture documented

## Outcome
Remote administration now uses key-based authentication and follows current security best practices for a small homelab.
